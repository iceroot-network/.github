# IceRoot community

The project directory and shared contribution guidelines for IceRoot, a post-quantum asset-continuity network.

Mono Labs R&D LLC builds IceRoot and [Monolythium](https://monolythium.com), led by [Nayiem Willems](https://github.com/NayiemW). IceRoot focuses on native assets and their continuity across networks. Monolythium focuses on programmable applications and execution.

LYTH is planned to launch on IceRoot and migrate to Monolythium when its network is ready, using the ordinary asset and migration rules available to other projects. ROOT is IceRoot's separate token for fees and voting.

Heartwood's engineering sequence starts with ARK and Solar protocol designs, a new Rust implementation checked against a pinned Solar reference, then IceRoot-specific protocol changes.
