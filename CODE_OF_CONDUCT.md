# Code of conduct

IceRoot welcomes contributors of every background and experience level.

- Treat people respectfully. Discuss the work without personal attacks.
- Make room for questions and different perspectives.
- Respect privacy. Do not share another person's private information.
- Harassment, discrimination, threats, and sexualized behavior are not acceptable.

These expectations apply to project issues, pull requests, discussions, and community spaces. Maintainers may edit or remove harmful content, limit participation, or block repeat offenders.

Use GitHub's **Report content** option to report abusive content privately to repository administrators or GitHub.
